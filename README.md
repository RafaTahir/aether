# Aether

Borderless project investments, built as a Solana devnet architecture prototype.

The application lives in `projects/border-invest` (the directory name is retained for workspace compatibility). It supports fictional, milestone-led project discovery, Solana devnet wallet connection, diligence briefs, and compliance/custody integration boundaries.

## Run locally

```shell
cd projects/border-invest
npm install
npm run dev
```

Open `http://localhost:3000`.

This repository is a prototype. It does not accept funds or make investment offers. Read the application [README](projects/border-invest/README.md), [architecture](projects/border-invest/docs/ARCHITECTURE.md), and [design research](projects/border-invest/docs/DESIGN-RESEARCH.md) before building production transaction flows.
